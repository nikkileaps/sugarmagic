Paper dialogue box — can a deckled edge flex?

Same layout in every panel — auto-width chip overlapping an auto-height panel, text reflowing, arrow and flourish anchored bottom-right. Only the paper differs. Judge the edge as the boxes get taller: that is where a repeating technique gives itself away. Gold and blue are the existing introduce/reinforce treatments, left untouched.

A — 9-slice border-image

Cheap, no runtime cost, corners crisp. The edge repeats; watch the left and right edges on the tall box.

B — SVG turbulence displacement

Rounded rect displaced by fractal noise. Noise lives in user space, so the edge never tiles no matter how tall the box gets. Texture comes from the same turbulence.

C — canvas-drawn

Deckle and fibre drawn per element size. Total control; redraws on resize.

Scale test — 1.0x vs 1.5x (technique B)

Everything is in relative units off --ui-scale, so the whole component scales without re-authoring.
